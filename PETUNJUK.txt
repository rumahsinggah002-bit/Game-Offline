TANGKAP BINTANG — VERSI 2 (PERBAIKAN BUG + SOUND)

Perbaikan:
- Gerakan keranjang dengan sentuhan hanya aktif saat area game ditekan dan digeser.
- Tombol kiri/kanan memakai pointer capture dan pelepasan kontrol lebih aman.
- Mencegah pemilihan teks saat menekan tombol.
- Kontrol keyboard ditambahkan.
- Efek suara saat mulai, menangkap bintang, terkena bom, dan game selesai.
- Tombol untuk mengaktifkan/menonaktifkan suara.
- Service worker memakai cache v2 agar file baru menggantikan versi lama.

UPDATE DI GITHUB PAGES:
1. Ekstrak ZIP.
2. Upload/ganti index.html, sw.js, manifest.json, icon.svg di repository GitHub yang lama.
3. Pastikan file berada di root repository.
4. Tunggu GitHub Pages selesai memperbarui.
5. Buka situs game saat online, lalu refresh. Jika masih versi lama, tutup tab dan buka ulang; service worker baru akan mengganti cache lama.
6. Setelah versi baru terbuka, game tetap bisa dimainkan offline.
